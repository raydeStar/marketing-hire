## Try it

```bash
powershell -File scripts/start-campaign-fixture.ps1
```

That starts a disposable demo host at `http://localhost:5190` (no model calls, sample ledger). The
host key is in the `dataRoot` named in `artifacts/campaign-fixture-active.json`. Open Campaigns →
Assignment details → **Create simulated campaign** to get a reviewable campaign. For the real
workspace use `scripts/start-marketing.ps1` as before.

**Compare the two looks:** Settings → Appearance → Style → *Clean* (violet, focused chat) or *Muse*
(your earlier charcoal-neutral direction, with the drag-resizable at-a-glance panel beside chat).
Both work in light and dark. Clean is the default; pick whichever you prefer.

## Decisions for you

1. **Style:** Clean or Muse (or keep both).
2. **Workspaces:** one per user (and a few members sharing one) needs Plow to run one isolated host
   + agent per workspace. See "Many users" in the operating-model doc.
3. **Teammates' reach:** collaborators see only shared campaigns and can't chat with the employee
   (chat spends the owner's model budget). Should members also get read access to the wiki, assets
   and Inbox? That's a permission change I did not make overnight.
4. **Public pages:** this host refuses Tailscale Funnel traffic by design, so `/p/<address>` links reach
   only people who can reach the workspace until Plow serves them publicly.
